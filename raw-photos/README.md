# 행사 사진 올리는 곳

여기에 사진을 올리면 GitHub Actions 가 알아서 리사이즈하고 갤러리에 넣는다.
사진 편집도, 파일명 규칙도, YAML 수정도 필요 없다.

## 올리는 법 (GitHub 웹)

1. 이 폴더에서 **Add file → Upload files** 를 누른다.
2. 주소창의 경로 끝에 `앨범ID/` 를 직접 적어 새 폴더를 만든다.
   예: `raw-photos/kcc2027/` — 사진을 드래그하기 전에 파일명 앞에 `kcc2027/` 를 붙여도 된다.
3. 사진을 전부 드래그해서 놓고 **Commit changes**.

앨범 ID 는 영문 소문자·숫자로 짧게 짓는다: `kcc2027`, `ksc2026`, `mtWorkshop2027` (X).
이미 있는 앨범에 사진을 더할 때는 그 폴더에 그냥 올리면 된다.

## 올리고 나면

`Process gallery uploads` 워크플로가 1~2분 안에 돌면서

- 긴 변 1600px WebP 로 변환하고 400px 썸네일을 만들고,
- **EXIF 를 지우고** (원본에는 촬영 위치와 시각이 그대로 들어 있다),
- `content/gallery.yaml` 에 앨범 항목을 만들거나 갱신하고,
- **원본을 지운 뒤** 커밋한다.

그다음 `Deploy` 가 이어서 돌아 사이트에 반영된다. 이 폴더가 다시 비어 있으면 정상이다.

## 사람이 손볼 것

워크플로는 앨범 제목을 폴더 이름에서 대충 만들고 날짜를 오늘로 적는다.
`content/gallery.yaml` 에서 `title` 과 `date` 를 실제 행사에 맞게 고치면 된다.
`cover` 는 파일명에 `group` 이 들어간 사진을 우선 고르므로,
단체사진 파일명에 `group` 을 넣어 올리면 썸네일이 알아서 단체사진이 된다.

`title`·`caption` 은 한 번 고치면 다음 업로드에서 덮어쓰이지 않는다.

## 인물 사진은 여기가 아니다

멤버 프로필 사진은 `raw-photos/members/<slug>.jpg` 로 두고
`npm run optimize-member-photos` 를 로컬에서 돌린다. 갤러리 워크플로는 이 폴더를 건드리지 않는다.
